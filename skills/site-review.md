name: site-review
description: Review the Path of Resilience website for content quality, UX issues, broken elements, and accessibility. Use when you want a structured audit of the site before publishing changes.
---

Review all HTML files in this repository for the Path of Resilience coaching website.

For each file, check:
1. **Content** — Is the copy compelling, typo-free, and on-brand for a resilience coaching practice?
2. **Structure** — Are sections logically ordered? Is the call-to-action (booking) prominent?
3. **Links** — Are all internal links valid? Do external links (booking, social) point to real destinations?
4. **Responsiveness** — Do the meta viewport tag and CSS media queries exist?
5. **Accessibility** — Do images have alt text? Do form inputs have labels? Is color contrast sufficient?
6. **Performance** — Are large scripts deferred? Are Google Fonts loaded efficiently?

Report findings as a short bulleted list grouped by file, with severity labels: **Critical**, **Warning**, or **Suggestion**.
